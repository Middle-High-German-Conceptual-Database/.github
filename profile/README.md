# Middle High German Conceptual Database (MHDBDB)

The **Mittelhochdeutsche Begriffsdatenbank (MHDBDB)** at the University of Salzburg is a long-term research infrastructure for Middle High German literature. It brings together semantic resources, digital corpora and AI-assisted research methods.

[MHDBDB website](https://www.mhdbdb.sbg.ac.at) · [Explore the TEI corpus](https://dhcraft.org/mhdbdb-tei-only/) · [Research playground](https://dhcraft.org/mhdbdb-tei-only/playground/)

## Projects and development

- **[MHDBDB-next](https://github.com/Middle-High-German-Conceptual-Database/MHDBDB-next)** provides the project overview and entry point to the semantically annotated TEI corpus.
- **[mhdbdb-tei-only](https://github.com/DigitalHumanitiesCraft/mhdbdb-tei-only)** hosts the corpus data, code, documentation and ongoing development in collaboration with Digital Humanities Craft.
- **[MHDBDB-graph](https://github.com/Middle-High-German-Conceptual-Database/MHDBDB-graph)** contains the GraphDB/RDF-based MHDBDB stack.

For corpus issues, suggestions and data contributions, use the [TEI project's issue tracker](https://github.com/DigitalHumanitiesCraft/mhdbdb-tei-only/issues).
